# GEMA Dashboard

Interactive explorer of gender representation in Portuguese sports media (2010–2023).

Covers three major newspapers (A Bola, O Jogo, Record) and seven online sources (SAPO, Notícias ao Minuto, ZAP, Euronews).

Built with Streamlit + Plotly. Data pre-processed from a corpus of ~200k articles and ~11k sports covers.
